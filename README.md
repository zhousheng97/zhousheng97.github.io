# zhousheng97.github.io

https://zhousheng97.github.io/

Built with the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme.

- Name / position / links / avatar: `_config.yml`
- About, research, news, honors: `index.md`
- Publications: `_data/publications.yml` (thumbnails in `assets/img/pubs/`)
- Services: `_includes/services.md`

GitHub Pages builds the site automatically on push (Settings → Pages → Deploy from branch `main`, root).
The previous hand-written homepage is available in the git history.
